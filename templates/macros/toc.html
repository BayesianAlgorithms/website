This is a simplified single-marker variant of the workaround used in the Academic Workshop theme's macros/list.html, which additionally carries a section name through paired markers: here there is only one chapters section, so no parameters are needed. Note that the insert macro refers to its sibling macro through the toc namespace rather than self, since Tera does not resolve self across an import boundary, so this file must be imported as toc by any calling template.
